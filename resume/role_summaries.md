# Summary of Tech Lead Roles
- Coordinate and facilitate team Scrum planning ceremonies
- Manage, mentor, and help grow developer careers
- Recruitment (Interviewing and assessment reviews)
- Collaborate with the business to prioritize project requirements backlog
- Collaborate with the team to decompose requirements into implementable software components
- Mentor Team
- Design, implement, and maintain software systems
- Review software component designs and implementations
- Execute PROD releases

# Summary of Role - Senior Software Developer:
- Design and implement software systems
- Review software components implementations
- Onboard other developers onto the team and the Transactions domain
